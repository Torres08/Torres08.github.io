# Juan Luis Torres Ramos — Cybersecurity Portfolio

Minimalist terminal-brutalist cybersecurity portfolio deployed to GitHub Pages.

## Stack
- **Vite + React + TypeScript**
- **Tailwind CSS** (`IBM Plex Mono`, `#000000` canvas, `#9A6CC6` accent)
- **GSAP** character-scramble & stepped reveal animations

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
